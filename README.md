# Sprint_6
Проект содержит автоматизированные API-тесты для сервиса **Яндекс Самокат** с использованием Python и REST-клиентов.

## 📊 Покрытие тестами

### 🚴 Тесты работы с курьерами
- **Создание курьера**:
  - Успешная регистрация
  - Ошибка при дублировании логина
  - Проверка обязательных полей (логин, пароль)
  
- **Авторизация курьера**:
  - Успешный вход
  - Неверные учетные данные
  - Проверка валидации полей
  - Отсутствие обязательных данных

### 📦 Тесты работы с заказами
- **Создание заказа**:
  - Все варианты цветов:
    - BLACK
    - GREY
    - Оба цвета
    - Без указания цвета
  - Проверка наличия track-номера
  
- **Получение списка заказов**:
  - Базовая проверка структуры ответа
  - Работа с параметрами:
    - Ограничение количества (`limit`)
    - Пагинация (`page`)
  - Проверка структуры данных заказа

## 🛠️ Технологический стек

- **Python 3.11+**
- **Pytest** (тестовый фреймворк)
- **Requests** (HTTP-клиент)
- **Allure Report** (визуализация результатов)
- **GitHub Actions** (CI/CD)
